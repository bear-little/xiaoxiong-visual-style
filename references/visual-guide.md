# 原图视觉分析：修订版

依据七张用户作品逐张对照。外观可观察，具体字体、软件、算法、混合模式尚未证实。此前两张生成封面未获认可，不作为参考。

## 物体的纹理

[打字机叙事帧](images/03-typewriter.png) 与 [打字机封面](images/07-typewriter-cover.png)：

- 保留照片式透视、起伏、遮挡、机械细节与体积，同时将连续明暗大幅压成橙色实地与纸白。
- 外壳有连片橙色。白色既有连续的高光细边，也有不规则大小的蚀孔、碎斑；不是所有部位都有均匀的小圆点。
- 底座前沿可见较大、成行的网点；外壳中部更碎、更密，顶部机械结构又更零散。网点尺度和密度随部位不同。
- 局部仍有桃色中间层次。轮廓存在细小橙蓝边缘错位，不是明显重影。
- 键帽有透视、厚度、短柱和柔软投影；它们与机器接受同类纹理处理，蓝色也可存在于键帽和局部物体。
- 叙事帧底部的柔灰落影保留空间。不能转成纯平面图标，也不能改成靠无数细线构成的精密雕刻插画。

实现建议：使用有摄影体积的素材，先压缩灰阶与建立色块，再结合阈值碎斑、半调和色彩映射。保留大块墨色、白色孔洞与局部网点三个层次。具体算法按素材试验，不声称知道原作者滤镜。

[蝴蝶](images/04-butterflies.png)：左上是近乎镂空的破碎纹路，中上有明显圆网点，右上小点更规则；下排又有淡桃色、白色羽脉、渐隐和细碎分色。它证明同一系统可以使用多种强度与处理，不能统一套一个网点滤镜。

[羽毛笔](images/05-quill.png)：羽脉为高反差橙白细结构，羽面密集碎点；笔尖、墨瓶有体积与灰投影；墨迹为近黑、自然不对称的轨迹和飞溅。

[星系](images/01-knowledge.png)：橙蓝颗粒构成疏密变化的环带，散点沿方向逸出；不是干净椭圆描边。[灯塔](images/06-lighthouse.png)：塔身大片白色与橙色碎斑并存，蓝色海浪保留摄影泡沫和明暗；部分半调呈小方孔感，光束则是规则点阵渐弱。光束和物体纹理承担不同角色。

## 背景与色彩

背景近白、低饱和浅灰纸面，细小横纵纤维、碎颗粒和低强度冷暖杂色可见。颗粒让文字、物体像处于同一个输出表面。物体的中粗网点、背景的细噪点、边缘的轻色差是三个尺度，不能全部概括为纸纹。

禁止明显米黄染底、黄褐羊皮纸和大颗粒凹凸水彩纸。用户明确反馈生成图太黄。局部浅桃高亮与粉橙色光晕不代表背景要黄。

纯背景对照[羽毛笔](images/05-quill.png)、[蝴蝶](images/04-butterflies.png)和[界面样式图](images/02-interface.png)的空白区域。背景层保持平面和大面积近白。色晕只托住局部文字或构图落点，细线淡到退居底层。若任务给了满幅水彩作为待改素材，同时要求完整贴合个人风格，优先以这三张原作的底面为准，去除大面积水彩色带和泛黄。

主体是亮橙、偏紫相的中蓝与近黑，有淡桃中间层次。色值未准确采样，不设所谓官方 HEX；也不固定每幅橙蓝比例。

## 字体的角色和形态

对照 [界面样式图](images/02-interface.png)。

1. 中文宋体式：横细竖粗、尖锐三角衬线、明确撇捺，标题正文都出现。不是现代黑体正文系统。边缘有轻微橙蓝错位和颗粒，但字形清楚。
2. 英文直立展示字：Linkly AI、Butterfly 为高对比衬线，细衬线与圆润弧线并存；并非正文打字机字。
3. 英文斜体展示字：Typewriter 较厚、宽而饱满，有明显书籍衬线气质，横跨物体。不能用极纤细、光洁、细长的时尚斜体替代。
4. 英文叙述和标签：Keys strike、Ink carries、Words mechanized、START SYSTEM 等为等宽打字机字；板状衬线、宽字面、机械节奏，轮廓略粗粝。不是细小光滑代码字体，也不靠任意字体增加字距替代。分行、段间空白共同建立节奏。
5. 功能字和标志：知识库封面左上 Linkly AI 为较干净无衬线，手写 l 为独立标志；不要推广成所有标题规则或复制到无关封面。

仅凭位图无法确定准确字体名。宋体族、直立高对比衬线、粗斜体、板状衬线等宽字体只是选择方向。用相同单词比较字宽、字重、衬线及 a/r/y 等形态；候选名称不能作为识别结论。精确名称需要源工程或字体列表。

## 装饰的四类形态

### 平薄高亮条

Ready for every agent、START SYSTEM、SEARCH KNOWLEDGE、Words mechanized 背后为浅桃半透明条。边缘略不齐，有局部下划线延伸、重叠色。没有厚度、翘角或明显胶带齿口。此前生成图的厚实撕边胶带不匹配。

### 局部柔焦光晕

Butterfly 标题下、Linkly AI 基线下、羽毛笔文字附近可见淡粉橙色团，边缘融入白底；部分是细长模糊发光下划线。范围有限，不是暖色全屏渐变。

### 界面细线

窗口标题栏、关闭叉、方形左右箭头、折角文件夹、虚线选框与小控制点、鼠标指针、输入框都以极细近黑线构成。线有轻微不齐和色差，但结构准确。辅助线、大圆极淡，主界面线略深。不是随手涂鸦，也不是每张都加编号、FIELD NOTES、黑色套准标靶的复古海报模板。

### 标点与主题附属物

黑橙错位小方块、橙色引号、星系四角星与散点、分离键帽、小蝴蝶和墨迹各有语义。选择局部出现，保持疏密与大小关系，不能平均撒满。

## 构图逐张依据

- 打字机封面：机器偏右，蓝色粗斜体由左跨入机器，左下高亮短句与键帽形成次落点。叠合处深色关系可见，但不能断言具体混合模式。
- 打字机叙事帧：机器左侧大幅出血，右侧数行文字留明显停顿，不另加中英文双大标题。
- 羽毛笔：左文、右侧斜向巨物、底部墨迹连接两区。
- 蝴蝶：居中标题、两行三列图鉴，右下说明，极淡定位线。
- 灯塔：左侧竖向锚点、下方横向蓝色海面，光束与右侧文字呼应，空白承载隐约文字。
- 产品首屏与样式页：允许功能卡片、框线与更高密度，不套单标题封面规则。

留白不是固定左右均分。用户否定生成封面，不等于禁止交叠、裁切与蓝色标题。上一轮把标题分开只是一次试做，不是已确认风格。

用物体之间的大小、间距、遮挡和淡投影建立画面关系。打字机的边缘裁切与散落键帽适用于有一个清晰主物的构图。蝴蝶图的独立陈列适用于需要逐件看清的成组物。活字试稿中的排字工作台和挤成一串的放大字块都未获认可。成组物件可先尝试图鉴式陈列，但活字的最终构图仍待校准。

## 后续校准

先对照一块物体纹理、一组真实文字和高亮/光晕，而非直接做完整封面并声称匹配。逐项检查摄影体积、色块、白孔、网点尺度、字重字宽、浅条形态。动画目前仅有静帧依据，运动节奏仍待视频校准。
